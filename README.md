# Team Undefined Behavior

`eval` принимает один вычисляемый аргумент. Если результат — список, он
исполняется как выражение F в текущем окружении: `(eval '(plus 1 2))` возвращает `3`.
Литералы, символы и функции возвращаются без повторного вычисления.
`eval` можно передавать как значение; созданные через него замыкания сохраняют
доступ к окружению своего создания.
